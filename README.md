# DAYWEAR WebGL Site

Premium WebGL landing page and collection mockup for DAYWEAR.

## Files

- `index.html` - main GitHub Pages entry point
- `styles.css` - all styling
- `app.js` - WebGL scene, routing, interactions, product pages
- `404.html` - GitHub Pages fallback for direct collection URLs

## Deploy On GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. Go to `Settings -> Pages`.
4. Set source to `Deploy from a branch`.
5. Select `main` and `/root`.
6. Open the Pages URL after GitHub finishes deploying.

The site uses hash routes like `#/collections/zip-hoodies` so it works under normal GitHub Pages project URLs.
